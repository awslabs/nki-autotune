# Learnings

## Code Quality
- Don't rebuild derived maps in hot paths — cache on `id(obj)` at module level (per-call `inspect.getsource` = 50×+ slower). *(2026-04-23 10:00 ET)*
- **No `load_block`/`matmul_block`/`allocate_buffers` gadgets** — tile loops IR-positioned; bare `nl.ndarray`+`nisa.dma_copy`/`nc_matmul` at op fire depth. **`nl.ndarray` N-D explicit** `(P, num_p_tiles, F_contig)`; bare `128` (no `nl.par_dim`). *(2026-04-26 11:00 ET)*
- **Loud failures only**: no silent raises, no `try/except` to adapt around malformed IR — reject bad input. A no-op-on-bad-input transform returning "success" is the same violation. **Single return per function** (user rejects branching returns). *(2026-06-01 22:00 ET)*
- **Transform legality = behavior/dep-order + ISA well-formedness ONLY; NEVER resource capacity** (user-locked): a dep-legal kernel that over-subscribes PSUM/SBUF is a VALID output — compile/HW profiling prunes it (gym-1 CONFIRMED: full-extent-buffer rungs exit 70 at BIR-verify, the intended pruning). DO reject malformed IR / dep violations / ISA-impossible ops; DON'T gate "won't fit in PSUM". *(2026-07-03 10:00 ET)*

## Verification
- **Byte-exact transform verification**: gate = `render(apply(before_IR)) == <hand kernel>`, NOT "roughly the same" (user: "same means same"). Oracle (`_ladder_compare.py`) **AST-canonical**. **The hand fixture MUST encode the SPEC shape, NOT the transform's own captured render** — else "byte-exact ✅" only means "matches what it emitted". Author by hand. **Decl-hoist is TOP-LEVEL ONLY** → **in-loop decl position IS significant**. *(2026-06-24 11:00 ET)*
- **Goal = REPRODUCE `kernel_target` exactly, not "equivalent"** (user-locked: "no cheating, don't act smart"): when MFU is flat, **literal-diff and close EVERY difference** — don't rationalize a delta as a separate optimization. "Only N blockers left" is unprovable short of byte-exact repro. *(2026-06-21 16:00 ET)*
- **Numeric sim is a WEAKER oracle than dependency-order** — legality = dep-order preservation, NOT numeric luck. memset-into-K / drain-sunk-into-K sim "correct" by last-write-wins yet violate producer/consumer order + break HW; rejecting is RIGHT even when sim passes. **Behavior-preserving legality refactor → GOLDEN-VERDICT gate** (a topological swap can over-permit `illegal→ok` while suite+sim stay GREEN). *(2026-06-04 16:00 ET)*
- **Transforms COMPOSABLE + always-correct-when-legal** (user-locked): EVERY intermediate kernel MUST be correct — a wrong one (k16/k17 NaN) means **the legality check failed to reject it; fix the CHECK, not the ladder** ("the solution is not 'let's not do this ladder'"). Verify each rung first. *(2026-06-21 20:00 ET)*
- **FP32 validation contract**: CPU-sim runs fp32 (inputs cast, SBUF/PSUM→`nl.float32`, fp32 golden); HW keeps original. End-to-end `atol=rtol=5e-3` (`assert_allclose` raises+halts); unit — elementwise `1e-6`, matmul `1e-5`, reduce `1e-4`. **`simulate_fp32` (`nkigym.synthesis`) sims bare `@nki.jit` kernels vs numpy golden** (`examples/*.py` auto-discovers each `kernel_<id>`). *(2026-06-23 12:00 ET)*
