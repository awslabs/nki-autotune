# Learnings

## Code Quality
- Don't rebuild derived maps in hot paths — cache on `id(obj)` at module level (per-call `inspect.getsource` = 50×+ slowdown). *(2026-04-23 10:00 ET)*
- **No `load_block`/`matmul_block`/`allocate_buffers` gadgets** — tile loops IR-positioned; bare `nl.ndarray`+`nisa.dma_copy`/`nc_matmul` at op fire depth. **`nl.ndarray` N-D explicit** `(P, num_p_tiles, F_contig)`; bare `128` (no `nl.par_dim`); `nisa.dma_copy`>`nl.load`. *(2026-04-26 11:00 ET)*
- **Loud failures only**: no silent raises, no `try/except` to adapt around malformed IR — reject bad input. A no-op-on-bad-input transform that returns "success" is the same violation. **Single return per function** (user rejects branching returns). *(2026-06-01 22:00 ET)*
- **Transform legality = behavior/dep-order + ISA well-formedness ONLY; NEVER resource capacity** (user-locked): a dep-legal kernel that over-subscribes PSUM/SBUF is a VALID transform output — compile/HW profiling prunes it. DO reject malformed IR / dep violations / ISA-impossible ops (sub-128 `nc_matmul`); DO NOT gate "won't fit in PSUM". *(2026-06-06 06:00 ET)*

## Architecture
- **`nkigym/__init__.py` lazy `__getattr__`**: eager re-exports drag heavy deps (`claude_agent_sdk`) into gym workers — keep `__init__` empty of compile/synthesis loads. **Editable pip install pins source path** across shared-venv worktrees: subprocess tests pick up installed path not cwd → `PYTHONPATH=<worktree>/nkigym/src`. *(2026-05-07 13:00 ET)*
- **Neuron allocator** Chaitin-Briggs+zone-aware: `address=` annotations skip `AddressRotation::run` → ~48pp MFU loss. *(2026-04-26 04:00 ET)*
- **Material-blocking**: reading PSUM w/ open material-blocking → `NCC_ISCH714`. Memset PSUM only when `PSUM_DTYPE=fp32`; transpose bf16 PSUM must NOT memset → `NCC_IBIR441`. HW mandates fp32 for `tensor_scalar.operand0/1`, `activation.scale`. HW rejects 4D affine-select dst (`NCC_INLA001`). *(2026-04-23 10:00 ET)*
- **Path B (own IR) > Path A (fork neuronx-cc)** — Path A ceiling = compiler IR (no online fusion/rotation/SW-pipeline/PSUM-bank addrs). **Decision: faithfully PORT exactly TVM's TensorIR schedule layer + `arith`** (NOT Relax/TE/topi); single target; win = online fusion + agent-legibility. *(2026-06-03 02:00 ET)*
- **arith substrate SHIPPED (`nkigym/ir/arith/`)**: faithful TVM `src/arith/` port. TVM dep **test-only** (`importorskip`), shipped `nkigym/` imports zero tvm. `can_prove_equal` can't fold `(f//c)*c+f%c→f` — use `detect_iter_map`. *(2026-06-03 12:00 ET)*
  - **Test-slimming = dedup/parametrize, PRESERVE EVERY ASSERTION** (user-locked): `@parametrize` near-identical tests, hoist helpers to `_fixtures.py`.
- **Repo scope**: `NKIOps` + `KernelIR` (`ir/ir.py`, wraps `DimensionAnalysis`+`KernelTree`) build + `render` to NKI; `.dump(cache_dir)` → markdown + tree PNG + `kernel.py`. *(2026-06-01 22:00 ET)*
- **NO trip-1 ForNodes anywhere**: a dim's iteration = factorization `(trip₀…trip_{k-1}, tensorize_size)`, product = extent; ForNode exists ONLY when trip > 1; innermost `tensorize_size` = ISA-leaf width. **Three load-bearing layers**: `iter_var.dom`, ForNode trips, `BufferRegion (lo,width)`; invariant `Π(trip)×width == dom`. *(2026-06-01 02:00 ET)*
- **BlockNode IR** (`tree.py`, nx.DiGraph): payload union `BlockNode|ForNode|ISANode`. `BlockNode` (TVM `SBlock`) owns `iter_vars` (axis+`dom`+role), `iter_values` (affine loop_vars→iter_var), `reads`/`writes`, `alloc_buffers`. **Blocks mechanically emitted** (canonical_build = one-per-op; transforms = fixed recipe); a block carries ONE role per axis → differing role forces its own block. `axis_map` = concrete→abstract (Split `d2`→op-axis `N`). *(2026-06-07 20:00 ET)*
- **SSA ops backend**: `f_nkigym` is SSA — `out = NKIOp()(src=…)`, allocate-and-return; `NKIAlloc`/`dst=`/authored memset GONE. Memset synthesized in `canonical_build` from `RMW_OPERANDS`. **Dtype** (`Buffer.physical_dtype`): PSUM accum ALWAYS fp32 (ONLY hardcode); else FIRST HBM input's dtype. *(2026-06-01 22:00 ET)*
- **LCA buffer placement, re-derived after EVERY transform** (`place_buffers`): each `Buffer` on the LCA BlockNode of all blocks touching it — the PSUM-hoist lever (compute_at co-locating memset/matmul/copy drops LCA). `shared_hbm` pinned at root (else re-alloc → NaN). **Location enum `{shared_hbm, sbuf, psum}`** (literal IS var prefix; HBM 2D, SBUF/PSUM 3D). *(2026-06-02 10:00 ET)*
- **Buffer-alloc granularity = the on-chip multi-buffer lever** (user-corrected, hand-tuning): one `nl.ndarray((P,V,F))` is **atomic** (whole `P×V×F` together or not at all); a **Python `list` of `(P,1,F)` ndarrays is liveness-scheduled independently** (not necessarily co-resident). So encode **multi-buffer degree** as the **2nd dim** `(P,deg,F)`, **number-of-tiles** as a **`list`**; lifting tiles to a list while keeping only `deg` on the tensor is the MFU knob. **All tensors stay 3D even at deg/tiles=1**; alloc at tightest enclosing-block scope. *(2026-06-18 18:00 ET)*
- **Producer-consumer deps = sidecar DAG** (`ir/dependency.py`, networkx; ISA-leaf/ForNode nids). Tree stays block-structural — don't reparent loops to encode RAW. **ONE notion: same buffer + overlapping region + RAW/WAW/WAR**; legality = leaf positions + spans. *(2026-06-03 02:00 ET)*
  - **Ill-defined-edge law**: `a→b` meaningless when one nests in the other → NO node↔loop edge; resolution = symbolic unroll, loop-carry via span-promotion. **Carry axis role-based**: `producer→outermost-loop-of-axis` edge only when enclosing loop non-PARALLEL AND axis ∉ output chunk. **Dep directions: freeze from ORIGINAL `ir.dependency`** — NEVER rebuild on the MOVED tree (tautological → NaN); eval via `first_backward_edge_for_insertion`.
- **Codegen direction: ir → codegen, never reverse.** Renderer takes IR primitives (tree/block nodes, `BufferRegion`s), not `KernelIR`. **loop_var naming**: dense `i_d{dim}_{N}`, N = ordinal among dim's ForNodes outer→inner. **Sibling order = dataflow**: splice `add_edge` at original child index. *(2026-06-01 04:00 ET)*
- **Transforms shipped: Split + Fuse + Reorder + ComputeAt/ReverseComputeAt + RFactor + SoftwarePipeline** (`nkigym/transforms/`). `Transform` base: `analyze(ir)→list[TransformOption]`, `apply(ir,option)→KernelIR` (deep-copy+mutate, re-checks → loud `TransformLegalityError`). **Split respects `MIN_TILE_SIZE`** (matmul K/M/N all 128) → M/K@128 unsplittable, N(512)→128. **compute_at**: shared `_move(...,is_reverse)`, faces differ ONLY in dep-check direction. Non-RFactor transforms can't merge/create blocks (block count invariant). *(2026-06-02 10:00 ET)*
- **compute_at TVM-faithfulness** (verified, detail in `tvm_knowledge.md`): TVM legality = 4 explicit checks PLUS implicit `require_stage_pipeline=true`; the **`region_cover` property** rejects a producer whose write region fails to cover a consumer's read. **KEY: block-granular deps CAN express init-domination via region-coverage, NOT a loop-node edge**; `_check_no_reduction_axis_covered` is OUR substitute. *(2026-06-09 00:00 ET)*
  - **TVM init = TWO-state model** (detail in `tvm_knowledge.md`): default WELDED (`block->init`, lowers PREDICATED `if reduce==min`); `decompose_reduction` extracts to a schedulable `SBlockRV`. **We're PERMANENTLY post-decompose** → never port init-field/predication/`decompose_reduction` (positional renderer can't emit `if`). **Init-domination dep-model PARKED** (user "revisit"): TVM block-granular+region_cover vs our loop-granular carry-edges BOTH give the guarantee; probe BLOCKED (TVM not built on desktop).
  - **compute_at/reverse legality TIGHTENED to STRICT SAME-PREFIX** (user-locked, `2026-06-12` spec): target's enclosing nest (outermost→`target_loop_nid`) as ordered `(dim,extent)` must be an EXACT prefix of the moved block's nest. Inner residual loops on dims the target doesn't iterate stay legal; partial split of a shared dim or different order → reject loud. **Rationale = NO DUPLICATION** (moving `[(d1,16)]`→`[(d2,4),(d1,16)]` replicates under `d2`; correct = tensorize-split `d2` THEN move). Caveat: matmul sometimes WANTS rhs-reload-under-M.
- **SoftwarePipeline SHIPPED (Tier B = stage assignment)** — faithful port of TVM `InjectSoftwarePipeline`. Knob = per-child-block `(stages, order)` on parent `BlockNode.annotations`; **version count DERIVED `use_stage−def_stage+1`** → `Buffer.versions`. Stageable = ALL direct loop children. Legality = TVM's 2 `ValidatePipelineBody` rules, NO capacity gate. **MEASURED: matmul 59.6%→83.4%.** *(2026-06-06 15:30 ET)*
  - **83.4% was the SoftwarePipeline-ladder ceiling**; the fused-RFactor merged ladder reaches `kernel_target`-equivalent via a DIFFERENT structure (two-stage fold + per-tile PSUM, no SW-pipeline).
- **RFactor: FUSED single-accumulator form SHIPPED** (`fbb1f5e`; `transforms/rfactor.py`), replacing old multi-slot terminal. **Split=role-preserving; RFactor=role-CHANGING** (flips factored loop ACC→PAR), legal ONLY via assoc+commutative reducer; `Split(K→ko,ki)∘RFactor(ko)`. `_emit_rmw` two-stage (spec 2026-06-12): per-output-tile PSUM (NO `factor`/`ko` slot, re-zeroed every `ko`=`init_two_stage_1`), `ki` HW-accumulates in PSUM, then `tensor_copy(psum→sbuf_rfactor)`+`tensor_tensor(sbuf_prod=add(sbuf_prod,sbuf_rfactor))` fold (=`drain_two_stage_0`), `sbuf_prod` memset once before `ko`(=`init_two_stage_0`). Fold carries `ko` ACC. INLINED emission (`ops/reduction_recipes.py` registry deferred). No loop reorder. **Why fused: NO `ko`-on-M term → `Split(M)` after RFactor stays machine-precision** (multi-slot baked `ko*m_tiles` onto psum's M axis → `normalize_block` dropped it → sim ~1.6e2). *(2026-06-20)*
  - **Carry-detector fix REQUIRED** (`ir/dependency.py`, `fbb1f5e`): fold has TWO `ko`-invariant operands → `_carry_loops_of_leaf` "ambiguous carried buffer". FIX: gate on `slot in op_cls.RMW_OPERANDS` — only a read-modify-written operand carries state (pure INPUT re-read / pure output written fresh do not).
  - **MERGE BLOCKER RESOLVED — single ladder canonical→kernel_target** (`113d630`+`5a602a1`; `examples/kernel_transforms.py` k0..k15): ONE IR with tiling AND the two-stage fold. `Split(K)→RFactor(ko)→Reorder×3(N above M, ki innermost)→Split-d2(memset/copy/fold)→Reorder×3(each→[N,M])→ReverseComputeAt(memset idx0 + copy idx-1 under matmul i_d1_0)` co-locates memset/matmul/copy per (N,M) tile → `compact_shapes` shrinks `psum_prod`→**(128,1,512)** HW-runnable; then `ComputeAt×2` sinks loads. **MEASURED gym-1: all k0..k15+kernel_target sim PASS ~1.4e-4; HW k15 46.08% MFU, kernel_target(hand) 90.81%.** Load-sink: **both-sunk +8.5pp**, **rhs-only-sunk HURTS** — measure, don't assume. RFactor **can't go LATE** (k15 `KeyError sbuf_prod`: drain already split/moved) → confirms go-EARLY. *(2026-06-20)*
  - **~45pp gap = PERF, structural** (blocker doc `docs/.../2026-06-20-fold-inlining-blocker-analysis.md`): k15 fold is a separate `[N,M]` sweep, NOT inlined into matmul innermost (`kernel_target`: `for Mi:{matmul;copy;tensor_tensor}`); lhs reloaded full-width. **N-outermost nest `N>ko>Mo>Mi>ki` IS transform-reachable + RFactor-clean** (probed) = the RIGHT fold-inlining precondition (fold reduces across ENCLOSING ko); shipped ko-OUTERMOST is wrong order. **TWO barriers**: (1) `_check_no_reduction_axis_covered` over-rejects — can't tell "cover by the enclosing loop the block's own init dominates (SAFE)" from "cover by a foreign loop sharing `i_d0_0` name (NaN)"; (2) frozen full-N COVER edge — RFactor emits memset/copy on full `psum[tile,0:2048]` (N untiled then) ≠ per-N-tile matmul → narrow region BEFORE move. See [[fused-rfactor-design-analysis]]. *(2026-06-20)*
- **Memset = sibling block, NOT nested `matmul.init`** (`BlockNode.init` dropped; permanently post-`decompose_reduction`). Init-domination = our loop-granular `memset→K-loop` carry edge (TVM equiv = region_cover). **Carried-init rule: a memset cannot sink INTO its own reduction loop** — `ComputeAt(init→K)` correctly rejected (re-zero per-iter → NaN). *(2026-06-09 12:00 ET)*
- **Loop-role placement (OP-LOCAL)**: `ForNode` role-neutral; role on `BlockNode.iter_var.role` (=`AXIS_ROLES[axis]`, default PARALLEL); same dim differs across ops. Split/Fuse role-blind; Reorder/compute_at consult. **3 roles**: PARALLEL, ACCUMULATION (reassociable — RFactor needs), SEQUENTIAL. **Reorder** = payload-swap adjacent parent-child ForNode pair; legal iff perfect-nest + no descendant SEQUENTIAL leaf on swap_dim. Bubbling N outermost = chained adjacent swaps. *(2026-06-07 20:00 ET)*
- **MFU SOTA vs nkipy baselines** (`@baremetal_jit`→HLO→`neuronx-cc -O2`): matmul_lhsT_rhs 90.92% (>86.65%); matmul_lhs_rhs 84%; rmsnorm+matmul ~79-80%; causal attn 13.20%. ## Verification
- `NCC_ISCH714` also fires on aliased `address=` RAW inorder. *(2026-04-23 10:00 ET)*
- **Byte-exact transform verification**: gate = `render(apply(before_IR)) == <hand kernel>`, NOT "roughly the same" (user: "same means same"). Oracle (`_ladder_compare.py`) **AST-canonical** (hoists decls, positional→keyword, sorts kwargs, distributes affine). **The hand fixture MUST encode the SPEC shape, NOT the transform's own captured render** — a fixture captured FROM a deviating render makes "byte-exact ✅" mean "matches what it emitted", never "matches spec". Author the fixture from spec by hand. *(2026-06-09 14:00 ET)*
- **Numeric sim is a WEAKER oracle than dependency-order** — legality = dep-order preservation, NOT numeric luck. memset-after-matmul / drain-sunk-into-K sim "correct" by last-write-wins yet violate producer/consumer order + break HW; a rejecting check is RIGHT even when sim passes. **Behavior-preserving legality refactor → GOLDEN-VERDICT gate, not the suite** (a topological swap can over-permit `illegal→ok` while suite + sim stay GREEN — capture each candidate's old verdict first). *(2026-06-04 16:00 ET)*
- **FP32 validation contract**: CPU-sim runs fp32 (inputs cast, SBUF/PSUM→`nl.float32`, fp32 golden); HW keeps original. End-to-end `atol=rtol=5e-3` (`assert_allclose` raises+halts); unit — elementwise `1e-6`, matmul `1e-5`, reduce `1e-4`. *(2026-05-06 17:00 ET)*
