# Learnings

## Code Quality
- Don't rebuild derived maps in hot paths — cache on `id(obj)` at module level (per-call `inspect.getsource` = 50×+ slower). *(2026-04-23 10:00 ET)*
- **No `load_block`/`matmul_block`/`allocate_buffers` gadgets** — tile loops IR-positioned; bare `nl.ndarray`+`nisa.dma_copy`/`nc_matmul` at op fire depth. **`nl.ndarray` N-D explicit** `(P, num_p_tiles, F_contig)`, bare `128` (no `nl.par_dim`). *(2026-04-26 11:00 ET)*
- **Loud failures only**: no silent raises, no `try/except` to adapt around malformed IR — reject bad input. A no-op-on-bad-input transform returning "success" is the same violation. **Single return per function** (user rejects branching returns). *(2026-06-01 22:00 ET)*
- **Transform legality = behavior/dep-order + ISA well-formedness ONLY; NEVER resource capacity** (user-locked): a dep-legal kernel that over-subscribes PSUM/SBUF is a VALID output — compile/HW profiling prunes it (gym-1 CONFIRMED). DO reject malformed IR / dep violations / ISA-impossible ops; DON'T gate "won't fit in PSUM". *(2026-07-03 10:00 ET)*
