# Learnings

## Code Quality
- Don't rebuild derived maps in hot paths — cache on `id(obj)` at module level (per-call `inspect.getsource` = 50×+ slower). *(2026-04-23 10:00 ET)*
- **No `load_block`/`matmul_block`/`allocate_buffers` gadgets** — tile loops IR-positioned; bare `nl.ndarray`+`nisa.dma_copy`/`nc_matmul` at op fire depth. **`nl.ndarray` N-D explicit** `(P, num_p_tiles, F_contig)`; bare `128` (no `nl.par_dim`); prefer `nisa.dma_copy`. *(2026-04-26 11:00 ET)*
- **Loud failures only**: no silent raises, no `try/except` to adapt around malformed IR — reject bad input. A no-op-on-bad-input transform returning "success" is the same violation. **Single return per function** (user rejects branching returns). *(2026-06-01 22:00 ET)*
- **Transform legality = behavior/dep-order + ISA well-formedness ONLY; NEVER resource capacity** (user-locked): a dep-legal kernel that over-subscribes PSUM/SBUF is a VALID transform output — compile/HW profiling prunes it. DO reject malformed IR / dep violations / ISA-impossible ops (sub-128 `nc_matmul`); DON'T gate "won't fit in PSUM". *(2026-06-06 06:00 ET)*

## Architecture

- **Path B (own IR) > Path A (fork neuronx-cc)** — Path A ceiling = compiler IR (no online fusion/rotation/SW-pipeline/PSUM-bank addrs). **Decision: faithfully PORT exactly TVM's TensorIR schedule layer + `arith`** (NOT Relax/TE/topi); single target; win = online fusion + agent-legibility. *(2026-06-03 02:00 ET)*
- **arith substrate SHIPPED (`nkigym/ir/arith/`)**: faithful TVM `src/arith/` port. TVM dep **test-only** (`importorskip`), shipped `nkigym/` imports zero tvm. `can_prove_equal` can't fold `(f//c)*c+f%c→f` — use `detect_iter_map`. *(2026-06-03 12:00 ET)*
  - **Test-slimming = dedup/parametrize, PRESERVE EVERY ASSERTION** (user-locked): `@parametrize` near-identical tests, hoist helpers to `_fixtures.py`.
- **Repo scope**: `NKIOps` + `KernelIR` (`ir/ir.py`, wraps `DimensionAnalysis`+`KernelTree`) build + `render` to NKI; `.dump(cache_dir)` → markdown + tree PNG + `kernel.py`. *(2026-06-01 22:00 ET)*
- **NO trip-1 ForNodes anywhere**: a dim's iteration = factorization `(trip₀…trip_{k-1}, tensorize_size)`, product = extent; ForNode exists ONLY when trip > 1; innermost `tensorize_size` = ISA-leaf width. **Three layers**: `iter_var.dom`, ForNode trips, `BufferRegion (lo,width)`; invariant `Π(trip)×width == dom`. *(2026-06-01 02:00 ET)*
- **BlockNode IR** (`tree.py`, nx.DiGraph): payload union `BlockNode|ForNode|ISANode`. `BlockNode` (TVM `SBlock`) owns `iter_vars` (axis+`dom`+role), `iter_values` (affine loop_vars→iter_var), `reads`/`writes`, `alloc_buffers`. **Blocks mechanically emitted** (canonical_build = one-per-op; transforms = fixed recipe); a block carries ONE role per axis → differing role forces its own block. `axis_map` = concrete→abstract (Split `d2`→op-axis `N`). *(2026-06-07 20:00 ET)*
- **SSA ops backend**: `f_nkigym` is SSA — `out = NKIOp()(src=…)`, allocate-and-return; `NKIAlloc`/`dst=`/authored memset GONE. Memset synthesized in `canonical_build` from `RMW_OPERANDS`. **Dtype** (`Buffer.physical_dtype`): PSUM accum ALWAYS fp32 (ONLY hardcode); else FIRST HBM input's dtype. *(2026-06-01 22:00 ET)*
- **LCA buffer placement, re-derived after EVERY transform** (`place_buffers`): each `Buffer` on the LCA BlockNode of all blocks touching it — the PSUM-hoist lever (compute_at co-locating drops LCA). `shared_hbm` pinned at root (else re-alloc → NaN). **Location enum `{shared_hbm, sbuf, psum}`** (literal IS var prefix; HBM 2D, SBUF/PSUM 3D). *(2026-06-21 16:00 ET)*
  - **Buffer alloc FORM + scope is MFU-CRITICAL, NOT inert** (MEASURED; CORRECTS "behaviorally inert"): k22 matched kernel_target's compute body yet ran **46.6% vs 90.7%** — all **buffer representation**. kernel_target uses a **list of separate `(128,1,512)` ndarrays alloc'd INSIDE each loop** (allocator rotates/double-buffers); we emit **ONE packed `(128,D,F)`** → loads serialize ([[nki-buffer-allocation-granularity]]). **Diffs after fold-inlining** (completeness unproven until byte-exact): (1) tightest-scope alloc placement SHIPPED (`ccc6a41`); (2) list-of-tiles emission [codegen]; (3) **store-sink — a LEGALITY blocker** (output block pinned at root); `sbuf_prod` per-N-block shape downstream; (4) rhs sank to wrong loop level; (5) **psum N-compaction needs a MISSING region-rebase transform** — to shrink `psum_prod`→(128,1,512), the drain's N-read must become the **enclosing** `i_d2_0` tile (like the matmul); `Split(d2)` only adds a fresh INNER `i_d2_1` (→ 4× sweep, MFU 27%), no-split leaves full-N — NO transform rebases a region onto an enclosing loop. M-compaction (co-locate under `i_d1_1`) works. NB kernel_target has TWO memsets: psum-init at innermost `i_d1_1` (RFactor places it right), `sbuf_prod`-init under N — psum-init under N → NaN.
- **Buffer-alloc granularity = the on-chip multi-buffer lever** (user-corrected, hand-tuning): encode **multi-buffer degree** as the **2nd dim** `(P,deg,F)` (atomic, pinned together), **number-of-tiles** as a **`list`** (liveness-scheduled independently); lifting tiles to a list while keeping only `deg` on the tensor is the MFU knob ([[nki-buffer-allocation-granularity]]). **All tensors stay 3D even at deg/tiles=1**; alloc at tightest enclosing scope. *(2026-06-18 18:00 ET)*
- **Producer-consumer deps = sidecar DAG** (`ir/dependency.py`, networkx; ISA-leaf/ForNode nids). Tree stays block-structural — don't reparent loops to encode RAW. **ONE notion: same buffer + overlapping region + RAW/WAW/WAR**; legality = leaf positions+spans. *(2026-06-03 02:00 ET)*
  - **Ill-defined-edge law**: `a→b` meaningless when one nests in the other → NO node↔loop edge; resolution = symbolic unroll, loop-carry via span-promotion. **Carry axis role-based**: `producer→outermost-loop-of-axis` edge only when enclosing loop non-PARALLEL AND axis ∉ output chunk. **Dep directions: freeze from ORIGINAL `ir.dependency`** — NEVER rebuild on the MOVED tree (tautological → NaN); eval via `first_backward_edge_for_insertion`.
- **Codegen direction: ir → codegen, never reverse.** Renderer takes IR primitives (tree/block nodes, `BufferRegion`s), not `KernelIR`. **loop_var naming**: dense `i_d{dim}_{N}`, N = ordinal among dim's ForNodes outer→inner. **Sibling order = dataflow**: splice `add_edge` at original child index. *(2026-06-01 04:00 ET)*
- **Transforms shipped: Split + Fuse + Reorder + ComputeAt/ReverseComputeAt + RFactor + SoftwarePipeline** (`nkigym/transforms/`). `Transform` base: `analyze(ir)→list[TransformOption]`, `apply(ir,option)→KernelIR` (deep-copy+mutate, re-checks → loud `TransformLegalityError`). **Split respects `MIN_TILE_SIZE`** (matmul K/M/N all 128) → M/K@128 unsplittable, N(512)→128. **compute_at/reverse** share `_move(...,is_reverse)`. Non-RFactor transforms can't merge/create blocks (block count invariant). *(2026-06-02 10:00 ET)*
- **TVM init = TWO-state model** (detail in `tvm_knowledge.md`): default WELDED (`block->init`, lowers PREDICATED `if reduce==min`); `decompose_reduction` extracts to a schedulable `SBlockRV`. **We're PERMANENTLY post-decompose** → never port init-field/predication/`decompose_reduction` (positional renderer can't emit `if`). *(2026-06-09 12:00 ET)*
- **Code-motion = SAME-PREFIX MERGE on DEPENDENT dims, NO region recomputation** (user-locked; replaces TVM `solve_iter_domains`/region-regen): **loop-nest MERGE** — prefix-match enforced **only on DEPENDENT dims** (loop vars the moved block binds), by `(dim,extent)`; **target loops the block does NOT bind become DUPLICATION loops** (replicate — correct for a pure producer/reload, rejected for ACCUMULATION). **`_move` VERBATIM-splices the subtree** (no normalize/region-regen) → byte-identical to the hand kernel. **PREREQUISITE: Split/Reorder/Fuse to match the dependent prefix FIRST** (lhs_T's K-loop Split to `ko(2)` before sinking); mismatch → reject loud. Duplication lets N-invariant lhs_T sink under matmul N = per-N reload (kernel_target's form). *(2026-06-22 00:00 ET)*
- **SoftwarePipeline SHIPPED (Tier B = stage assignment)** — faithful port of TVM `InjectSoftwarePipeline`. Knob = per-child-block `(stages, order)` on parent `BlockNode.annotations`; **version count DERIVED `use_stage−def_stage+1`** → `Buffer.versions`. Stageable = ALL direct loop children. Legality = TVM's 2 `ValidatePipelineBody` rules, NO capacity gate. **MEASURED: matmul 59.6%→83.4% (SW-pipeline ladder CEILING; the fused-RFactor ladder sits LOWER at 46% until buffer-form is solved).** *(2026-06-06 15:30 ET)*
- **RFactor: FUSED single-accumulator form SHIPPED** (`fbb1f5e`), replacing multi-slot terminal. **Split=role-preserving; RFactor=role-CHANGING** (flips factored loop ACC→PAR), legal ONLY via assoc+commutative reducer; `Split(K→ko,ki)∘RFactor(ko)`. `_emit_rmw` two-stage: per-tile PSUM (re-zeroed every `ko`), `ki` HW-accumulates, then `tensor_copy`+`tensor_tensor` fold carrying `ko` ACC, `sbuf_prod` memset once before `ko`. Must go **EARLY** (LATE → `KeyError sbuf_prod`). **Why fused: NO `ko`-on-M term → `Split(M)` after RFactor stays machine-precision** (multi-slot baked `ko*m_tiles` onto psum M → diverged). Merged ladder canonical→kernel_target (`113d630`); kernel_target(hand) **90.8% MFU** baseline. *(2026-06-20 12:00 ET)*
  - **Coverage-guard barriers FIXED** (B1 `ed5f61a`; B2 superseded by the prefix-merge model above): legality **OVER-REJECTION** blocked fold-inlining — **no new transform, no dep-model/IR overhaul** (user explored+rejected "loop=block" IR). **B1 keys NIDs not loop_vars** (post-RFactor foreign-K & own-`ko` both named `i_d0_0`); golden-verdict gated. **k0–k9** reach N-outermost `N>ko>Mo>Mi>ki` sim-clean — **OVERTURNS "RFactor sim-FAILs after Split(M)"**. **Fold-inlining BUILT + sim-clean** → remaining kernel_target gap in LCA bullet. - **Memset = sibling block, NOT nested `matmul.init`** (`BlockNode.init` dropped; permanently post-`decompose_reduction`). Init-domination = our loop-granular `memset→K-loop` carry edge. **Carried-init rule: a memset cannot sink INTO its own reduction loop** — `ComputeAt(init→K)` rejected (re-zero per-iter → NaN). *(2026-06-09 12:00 ET)*
- **Loop-role placement (OP-LOCAL)**: `ForNode` role-neutral; role on `BlockNode.iter_var.role` (=`AXIS_ROLES[axis]`, default PARALLEL); same dim differs across ops. Split/Fuse role-blind; Reorder/compute_at consult. **3 roles**: PARALLEL, ACCUMULATION (reassociable — RFactor needs), SEQUENTIAL. **Reorder** = payload-swap adjacent parent-child ForNode pair; legal iff perfect-nest + no descendant SEQUENTIAL leaf on swap_dim. Bubbling N outermost = chained adjacent swaps. *(2026-06-07 20:00 ET)*

## Verification
- `NCC_ISCH714` also fires on aliased `address=` RAW. *(2026-04-23 10:00 ET)*
- **Byte-exact transform verification**: gate = `render(apply(before_IR)) == <hand kernel>`, NOT "roughly the same" (user: "same means same"). Oracle (`_ladder_compare.py`) **AST-canonical** (hoists decls, positional→keyword, sorts kwargs, distributes affine). **The hand fixture MUST encode the SPEC shape, NOT the transform's own captured render** — else "byte-exact ✅" means "matches what it emitted", not "matches spec". Author the fixture by hand. *(2026-06-09 14:00 ET)*
- **Goal = REPRODUCE `kernel_target` exactly, not "equivalent"** (user-locked: "no cheating, don't act smart"): when MFU is flat, **literal-diff and close EVERY difference** — don't rationalize a delta as a separate optimization. **"Only N blockers left" is unprovable short of byte-exact repro** — enumerate verified diffs, don't claim the set is closed. *(2026-06-21 16:00 ET)*
- **Numeric sim is a WEAKER oracle than dependency-order** — legality = dep-order preservation, NOT numeric luck. memset-after-matmul / drain-sunk-into-K sim "correct" by last-write-wins yet violate producer/consumer order + break HW; a rejecting check is RIGHT even when sim passes. **Behavior-preserving legality refactor → GOLDEN-VERDICT gate, not the suite** (a topological swap can over-permit `illegal→ok` while suite+sim stay GREEN). *(2026-06-04 16:00 ET)*
- **Transforms COMPOSABLE + always-correct-when-legal** (user-locked): EVERY intermediate kernel in a chain MUST be correct — a wrong one (k16/k17 NaN) means **the legality check failed to reject it; fix the CHECK, not the ladder** ("the solution is not 'let's not do this ladder'"). Verify each rung before the next. *(2026-06-21 20:00 ET)*
- **FP32 validation contract**: CPU-sim runs fp32 (inputs cast, SBUF/PSUM→`nl.float32`, fp32 golden); HW keeps original. End-to-end `atol=rtol=5e-3` (`assert_allclose` raises+halts); unit — elementwise `1e-6`, matmul `1e-5`, reduce `1e-4`. *(2026-05-06 17:00 ET)*
