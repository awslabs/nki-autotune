# Learnings

1. **Every public action is atomic and generic**: one workload-agnostic, semantics-preserving transform per action, with every intermediate state correct. Intrinsic invariant repair is allowed; hidden scheduling choices, composites, aliases, presets, convenience wrappers, no-ops, and workload-specific implementations are not. *(2026-08-16 10:00 ET)*
2. **Transform legality is behavior/dependency order plus ISA well-formedness only, never resource capacity.** A dependency-legal kernel that oversubscribes PSUM or SBUF is valid output; compilation and hardware profiling prune it. Reject malformed IR, dependency violations, and ISA-impossible operations. *(2026-08-16 10:00 ET)*
3. **The optimization target is the literal manual-ladder endpoint.** When MFU is flat, diff against the expert endpoint and close every difference instead of rationalizing an "equivalent" structure as a separate optimization. *(2026-08-16 10:00 ET)*
4. **The front end is PyTorch-only.** `synthesize_torch_to_nkigym` lowers supported Torch graphs and NAKB `TorchReference`s, emits `f_nkigym` plus ABI adapters, builds IR, and validates fp32. Remove NumPy compatibility paths; workloads do not hand-code `f_nkigym`. Synthesis uses no model, prompt, search, or retry; current code/docs are authoritative. *(2026-08-16 10:00 ET)*
5. **The kernel library is the strict NAKB target registry.** Allow only `__init__.py` plus flat, self-contained `nakb_*.py` modules with the seven required fields. Discover every complete target, keep exact aliases only, retain unsupported targets, and never skip, xfail, or filter failures to pass. *(2026-08-16 10:00 ET)*
6. **FP32 correctness uses each workload's exact NAKB Torch reference, seeded inputs, `atol`, and `rtol`.** Preserve integer routing inputs while casting floating inputs and on-chip values to fp32. CPU simulation validates correctness; hardware profiling measures performance only. *(2026-08-16 10:00 ET)*
7. **Random-rollout coverage is fixed:** the first registered configuration of every workload type runs 500 transforms, records its random 63-bit seed, and simulates checkpoints at steps 50, 100, ..., 500. Generate rollouts concurrently, use all configured CPU-host capacity for grouped simulation, and fail the entire test after ten minutes. This preserves operation breadth without repeating every shape/configuration variant. *(2026-08-17 18:00 ET)*
8. **Numeric simulation is weaker than dependency-order legality.** Last-write-wins can make illegal memset or drain motion look numerically correct while breaking hardware. Treat behavior-preserving legality changes as golden-verdict changes and audit `illegal -> ok` transitions even when simulation stays green. *(2026-08-16 10:00 ET)*
9. **Public transforms directly define typed `analyze(ir)` and `apply(ir, option)`.** `apply` rechecks legality, copies, and fails loudly. The ordered `PUBLIC_TRANSFORM_TYPES`/`public_transforms()` registry must match the source-discovered inventory used by search, rollout, and acceptance tests. *(2026-08-16 10:00 ET)*
10. **Search is policy-driven linear refinement.** `run_search` owns one current state, rechecks each sequential action, profiles only the resulting state, and stops on policy completion, target, budget, or no actions. The built-in deterministic policy uses only abstract transform interfaces, generic structural priorities, scratch-state legality, and latency feedback. *(2026-08-16 10:00 ET)*
11. **OnlineFusion is contract-driven and incremental.** It preserves the existing tile width, rejects deferred-factor recurrences, and exposes independently useful one-stage prefix/completion states for arbitrary contract-proven chains; every prefix remains a valid kernel. *(2026-08-16 10:00 ET)*
12. **SoftwarePipeline owns pipeline scheduling explicitly.** Source-child order is fixed, an action selects one contiguous two-stage boundary, and buffer versions are `use_stage - def_stage + 1` for on-chip buffers only. An active pipeline exposes only explicit all-zero removal before retuning; other transforms reject overlap instead of silently cancelling it. *(2026-08-16 10:00 ET)*
13. **Producer-consumer dependencies live in a sidecar ISA-leaf DAG.** Edges are overlapping same-buffer RAW/WAW/WAR tagged by tensor. Freeze directions from the original dependency graph when evaluating moves; rebuilding after motion can flip RAW to WAR and hide violations. *(2026-08-16 10:00 ET)*
14. **CodeMotion uses same-prefix matching on ordered concrete `(dimension, extent)` pairs, never generated loop names.** It preserves reset frequency and pipeline stages, carries invariant RMW only without an intervening plain-write reset, rejects replicated full-buffer consumers, and treats non-bound target loops as duplication loops. *(2026-08-16 10:00 ET)*
15. **Buffer placement and compaction are separate actions.** Placement moves one on-chip declaration to its lifetime-safe LCA; compaction shrinks one logical shape and normalizes its regions while preserving `list_len`. Free-axis shrink appears only after motion makes the offset an enclosing anchor. *(2026-08-16 10:00 ET)*
16. **Buffer allocation form is performance-critical.** Multi-buffer degree is the second dimension of `(P, degree, F)`; tile count is a liveness-scheduled list. Factor `[P,T,F]` as `[[P,a,F]] x b` for any `a*b=T`, keep all tensors 3D, emit a uniform list even for `b=1`, and allocate at the tightest scope. *(2026-08-16 10:00 ET)*
17. **BufferLayout conserves logical tiles and sets `list_len`; SoftwarePipeline sets versions.** A versioned list has `tiles_per_list * versions` physical slots, renderer indexing selects both components, and `analyze` enumerates every divisor of the tile count. *(2026-08-16 10:00 ET)*
18. **Split, Fuse, and RFactor have distinct atomic boundaries.** Split and Fuse replace exactly two adjacent factors per action. Split never partitions a slot reduction; RFactor owns the coordinated `ko/ki` split, reset, copy, and fold without reordering, placement, or compaction. *(2026-08-16 10:00 ET)*
19. **First-write overwrite and identity-initializer deletion are separate actions.** Marking the first reduction write as overwrite must leave the initializer intact; delete the initializer only after it is independently dead. *(2026-08-16 10:00 ET)*
20. **Generated `loop_var` strings are not globally unique.** Legality, normalization, and rewrite bookkeeping must key node IDs and ancestry, then perform substitutions within the selected block hierarchy; global name-keyed maps can rewrite unrelated sibling loops. *(2026-08-16 10:00 ET)*
21. **Operation contracts must declare implicit, non-tileable index domains as fixed axes.** Examples include `NKIRangeSelect`'s complete width, both configured widths of nonzero-with-count, and the eight-wide domains of max/find-index operations. Split/Fuse must preserve these constructor-fixed domains. *(2026-08-16 10:00 ET)*
22. **Never create trip-count-one `ForNode`s.** A dimension is factorized as `(trip_0, ..., trip_n, tensorize_size)`; loops represent only trips greater than one, the tensorize size is the ISA leaf width, and product-times-width equals the iteration domain. *(2026-08-16 10:00 ET)*
23. **BlockNode IR is structural.** The tree contains `BlockNode | ForNode | ISANode`; each block owns iter vars/values, regions, and allocations, and blocks are emitted mechanically one per operation. One axis has one role per block, so differing roles require separate blocks. *(2026-08-16 10:00 ET)*
24. **Loop roles are operation-local.** `ForNode` is role-neutral; block axes are PARALLEL, ACCUMULATION, or SEQUENTIAL. Reorder swaps one adjacent perfect-nest pair, rejects descendant sequential axes, and requires dependency endpoints to agree on whether each loop indexes their tensor. *(2026-08-16 10:00 ET)*
25. **`f_nkigym` is SSA and operations allocate-and-return.** Canonical build synthesizes memset from `RMW_OPERANDS`. PSUM matmul accumulation is always fp32; otherwise physical dtype follows the first HBM input. *(2026-08-16 10:00 ET)*
26. **Do not add `load_block`, `matmul_block`, or `allocate_buffers` gadgets.** Tile loops are positioned in IR; codegen emits explicit N-D `nl.ndarray` plus bare `nisa.dma_copy`, `nc_matmul`, and other one-to-one ISA calls at operation fire depth. *(2026-08-16 10:00 ET)*
27. **Codegen flows from IR primitives to source, never backward through `KernelIR`.** Sibling order is dataflow, loop names are dense `i_d{dim}_{N}`, and buffer declarations use first-use anchors independently from allocation scope. `KernelIR.dump()` writes only `envelope.md` and formatted `kernel.py`. *(2026-08-16 10:00 ET)*
28. **Expression rendering must preserve AST precedence.** Parenthesize compound substitutions in multiplication, floor division, and modulo; bare-variable tests miss incorrect BufferLayout, pipeline, and RFactor slot expressions. *(2026-08-16 10:00 ET)*
29. **Partition axis `P` has a maximum of 128, not an inherent size of 128.** Current IR redundantly pins it to 128 through minimum-size metadata and `PARTITION_DIM`; supporting `P < 128` is separate work. BufferLayout must remain partition-agnostic. *(2026-08-16 10:00 ET)*
30. **Memset is a sibling block, never nested `matmul.init`.** The IR is permanently post-`decompose_reduction`; moving memset into the contraction loop re-zeroes live partial sums and violates producer-consumer order. *(2026-08-16 10:00 ET)*
31. **Respect Neuron material-blocking constraints.** Reading PSUM with material blocking open causes `NCC_ISCH714`; memset PSUM only for fp32, while bf16 transpose PSUM must not be memset. `tensor_scalar` operands and activation scale require fp32. *(2026-08-16 10:00 ET)*
32. **Transpose modeling stays ISA-accurate.** `dma_transpose` supports HBM-to-SBUF and SBUF-to-SBUF with matching dtypes; `NKITranspose` uses `nisa.nc_transpose(dst, data=...)`, SBUF-to-PSUM, matching dtype, and at most 128x128. Public tuning is pair insertion/cancellation plus operation-specific commute transforms. *(2026-08-16 10:00 ET)*
33. **The permanent architecture is an owned IR plus a TVM-derived arithmetic substrate, not a neuronx-cc fork.** `nkigym/ir/arith/` is a faithful standalone port with no shipped TVM dependency; use `detect_iter_map` where `can_prove_equal` cannot normalize div/mod identities. *(2026-08-16 10:00 ET)*
34. **TVM reduction initialization has two states; NKIGym is permanently post-decompose.** Do not port init fields, predication, or `decompose_reduction`; initialization is represented by a schedulable sibling block. *(2026-08-16 10:00 ET)*
35. **Keep package imports lazy.** Eager exports from `nkigym/__init__.py` load compiler/synthesis dependencies into workers. Editable installs pin a source path across worktrees, so subprocess tests need `PYTHONPATH=<worktree>/nkigym/src` when the shared venv points elsewhere. *(2026-08-16 10:00 ET)*
36. **Cache tree-wide analysis facts on hot paths.** Use `WeakKeyDictionary` keyed by `KernelTree`, share topology/access/pipeline facts across options, never rescan all blocks and ancestor chains per candidate, and invalidate mutation-sensitive caches immediately after rewrites. *(2026-08-16 10:00 ET)*
37. **Failures must be loud.** Do not use silent `try/except` adaptation, ambiguous `None`, or successful no-ops on malformed IR. Re-raise with context and prefer a single return per function. *(2026-08-16 10:00 ET)*
38. **Do not add pass-through wrappers.** Call the owning API directly; introduce an adapter only when it represents a real contract change. *(2026-08-16 10:00 ET)*
39. **Acceptance gates are registry-driven and package caps are fixed.** Tests call backend APIs rather than copying schedules. The structure gate enforces Black/isort, one-way imports, at most 25 public transforms, established package/per-file limits, and a closed Python layout under `nkigym/src/nkigym`: root `__init__.py` plus `codegen`, `ir`, `ops`, `profile`, `search`, `synthesis`, and `transforms`. Never raise or bypass these gates to pass. *(2026-08-17 18:00 ET)*
40. **Search acceptance measures end-to-end policy quality.** Each run reports its random seed, samples one configuration from five distinct NAKB workload types, runs the transform-selection policy, and requires every best latency to be at most `1.02 * best_historical_latency_ms`. Zero transforms are valid when the canonical kernel already qualifies; action count is not a separate acceptance condition. *(2026-08-17 18:00 ET)*
41. **Use `pytest.mark.parametrize` when cases differ only by inputs or configuration.** Each case should be independently scheduled and reported; use loops only for genuinely shared sequential state. *(2026-08-16 10:00 ET)*
42. **Use `~/venvs/kernel-env` and pass pytest paths before host options.** `--trn2-hosts` and `--cpu-hosts` are explicit, with no defaults; because the host options use `nargs="+"`, later paths become hostnames. Use `gym-trn2-1` for single-host hardware tests, add `gym-trn2-2` only for deliberate multi-host runs, and never reverse the alias to `trn2-gym-*`. Full CPU runs use `gym-cpu-1` through `gym-cpu-4`. *(2026-08-17 18:00 ET)*
43. **Remote correctness simulation is NumPy-only on CPU hosts.** Run the native NKI simulator first and invoke grouped fp32 matmul fallback only when the exact oracle misses. Detect host CPU counts, cap large-input pools, balance batches across hosts, and keep `profile_many` responsible for concurrent hardware work. *(2026-08-16 10:00 ET)*
44. **PyTorch tracing reset is process-global.** Keep registry synthesis sequential; parallelize transform analysis, rendering, and remote simulation instead of concurrently tracing workloads in one process. *(2026-08-16 10:00 ET)*
45. **`./install.sh --host <host>...` provisions `~/venvs/kernel-env` locally and remotely.** It installs local NKIGym/tooling and remote binary wheels, but does not provision drivers, activate shells, or replace the required NKI 0.5 and neuronx-cc 2.26 environment. *(2026-08-16 10:00 ET)*
46. **Progress reports must come from the period's actual diff.** Inspect `git diff origin/<branch>..HEAD`; do not narrate commit messages, specifications, memory, or stale learnings as completed work, and do not label user-authored fixtures as machine output. *(2026-08-16 10:00 ET)*
47. **Verify falsifiable source claims from source.** For TVM questions, bulk artifact classification, and semantic reviews, gather file-and-line evidence for each question; "source-traced" is not "proven," and review findings must be checked against structural possibility before adding tests. *(2026-08-16 10:00 ET)*
48. **Research locations are stable:** expert kernels and source locations are indexed in `references.md`; detailed TVM TIR findings and evidence levels live in `tvm_knowledge.md`. *(2026-08-16 10:00 ET)*
49. **When subagents are explicitly used, inherit the main-session model and verify their reports.** The controller owns remote runs and fixtures; hand-written ground-truth fixtures remain user-authored, and a credible blocked result is preferable to fabricated success. *(2026-08-16 10:00 ET)*
50. **Bound every tool call.** Oversized batched reads and wide parallel shell output repeatedly fail; use targeted `rg`, `head`, and chunked edits. *(2026-08-16 10:00 ET)*
51. **Git skills must not add a Claude co-author.** Consolidate unpushed commits non-interactively with `git commit-tree` on each group's end tree, preserve the final tree byte-for-byte, and verify an empty diff before moving the ref. *(2026-08-16 10:00 ET)*
52. **Read-only requests stop before edits.** For test-status or timing requests, report pass/fail, durations, and seeds without debugging, fixing, filtering, or reducing coverage; expected failures remain evidence until implementation is requested. *(2026-08-16 10:00 ET)*
53. **Routine progress updates should not repeat the current date.** Mention dates only when they affect the task. *(2026-08-16 10:00 ET)*
54. **The 2048-cubed bf16 matmul MFU ladder is roughly 16% -> 59% -> 83.7% -> 90.9%.** The steps are PSUM tiling/hoisting, accumulator double buffering, then sunk loads plus RFactor and scheduler-off; remaining gaps are operand-prefetch bubbles. *(2026-08-16 10:00 ET)*
55. **Neuron's Chaitin-Briggs zone-aware allocator is performance-critical.** Explicit `address=` annotations bypass `AddressRotation::run` and caused about a 48-point MFU loss. *(2026-08-16 10:00 ET)*
