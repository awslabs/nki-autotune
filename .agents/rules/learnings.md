# Learnings

1. **Every public action is atomic and generic**: one workload-agnostic, semantics-preserving transform per action, with every intermediate state correct. Intrinsic invariant repair is allowed; hidden scheduling choices, composites, aliases, presets, convenience wrappers, no-ops, and workload-specific implementations are not. *(2026-08-16 10:00 ET)*
2. **Transform legality is behavior/dependency order plus ISA well-formedness only, never resource capacity.** A dependency-legal kernel that oversubscribes PSUM or SBUF is valid output; compilation and hardware profiling prune it. Reject malformed IR, dependency violations, and ISA-impossible operations. *(2026-08-16 10:00 ET)*
3. **The optimization target is the literal manual-ladder endpoint.** When MFU is flat, diff against the expert endpoint and close every difference instead of rationalizing an "equivalent" structure as a separate optimization. *(2026-08-16 10:00 ET)*
4. **`$develop-nkigym` may edit `nkigym/src/nkigym/` and best-ladder records under `kernel_library/` only.** The targets in `benchmark/` and their checksum in `test/test_repository_structure.py` are frozen; benchmark revisions require an explicit user request. Honor later user authorization when resuming an older goal; do not re-block ladder updates because its stored wording is stale. *(2026-09-16 23:32 ET)*
5. **Keep `$develop-nkigym` a shorthand for the persistent Codex goal mechanism.** Use the actual goal tools, begin work immediately, and complete only when all repository tests pass. Pytest owns acceptance policy and thresholds; do not duplicate them in the skill or add a second prompt. *(2026-09-13 00:00 ET)*
6. **Performance acceptance is full-registry mean relative latency.** `test/test_nkigym_ladder.py` owns `mean(nkigym_latency_ms / nakb_latency_ms) <= 0.9`, using the arithmetic mean with equal weight per registered configuration. Every workload must pass correctness; individual latency regressions are allowed and remain in the mean. Draw and record a fresh random 63-bit seed per benchmark; set `NKIGYM_NAKB_VALIDATION_SEED` only for reproduction. *(2026-09-16 15:53 ET)*
7. **Pytest replays recorded ladders; it does not run agentic search.** Start from fresh canonical IR, require each recorded option to occur in `analyze`, apply sequentially, validate every intermediate numerically, then confirm final correctness and latency on Trn2. Use a simple loop; do not restore per-turn model orchestration or fixed search budgets. *(2026-09-13 00:00 ET)*
8. **NAKB acceptance uses each frozen benchmark target's Torch reference and AccuracySpec on seeded inputs and real Trn2 outputs.** ABI adapters must not recompute answers. Apply the target's output selection, views, grouping, and tolerances using its global-maximum or selected-value top-k comparison. Raw-byte equality is only for non-castable packed dtypes; CPU simulation is development coverage. *(2026-09-16 23:32 ET)*
9. **Reference fidelity can depend on accumulation and rounding order.** Higher-precision arithmetic can still fail a copied float32 reference; tiny upstream differences can cross FP8 quantization boundaries. Use the reference's operation and reduction order to diagnose these mismatches. *(2026-09-15 13:00 ET)*
10. **Selection lowering must preserve the copied reference's index order.** `topk` and `argsort` can differ on ties. Build router affinities from selected indices. Validate tied scores with distinct expert weights, because equal weights can hide incorrect routing. *(2026-09-15 13:00 ET)*
11. **`benchmark/` owns the frozen NAKB target registry; `kernel_library/` owns best NKIGym records.** The benchmark contains only `__init__.py` and flat, self-contained `nakb_*.py` modules with references, inputs, immutable `AccuracySpec` instances, and fixed `nakb_latency_ms`. It imports neither `nkigym` nor `kernel_library`. Keep best kernels as plain `BEST_NKIGYM_LADDERS` tuples of `(transform, option)` pairs in `kernel_library/_best_nkigym.py`; avoid wrapper subclasses or extra ladder frameworks. *(2026-09-16 23:32 ET)*
12. **The front end is PyTorch-only.** `synthesize_torch_to_nkigym` lowers supported Torch graphs and NAKB `TorchReference`s, emits `f_nkigym` plus ABI adapters, builds IR, and validates fp32. Remove NumPy compatibility paths; workloads do not hand-code `f_nkigym`. Synthesis uses no model, prompt, search, or retry; current code/docs are authoritative. *(2026-09-15 13:00 ET)*
13. **Random-rollout coverage is fixed:** the first registered configuration of every workload type except `hf_ffn` runs 500 transforms, records a random 63-bit seed, and simulates checkpoints at steps 50, 100, ..., 500. Generate concurrently and group simulations across all configured CPU hosts. One 600-second deadline covers synthesis, analysis/application, rendering, transfers, and simulation for the entire test. Only CPU rollouts exclude `hf_ffn`; registry and hardware coverage retain it. *(2026-09-15 13:00 ET)*
14. **Numeric simulation is weaker than dependency-order legality.** Last-write-wins can make illegal memset or drain motion look numerically correct while breaking hardware. Treat behavior-preserving legality changes as golden-verdict changes and audit `illegal -> ok` transitions even when simulation stays green. *(2026-09-15 13:00 ET)*
15. **Public transforms directly define typed `analyze(ir)` and `apply(ir, option)`.** `apply` rechecks legality, copies, and fails loudly. The ordered `PUBLIC_TRANSFORM_TYPES`/`public_transforms()` registry must match the source-discovered inventory used by rollout and structure tests. *(2026-09-15 13:00 ET)*
16. **Never relax repository acceptance gates to pass.** Preserve Black/isort, one-way imports, at most 25 public transforms, at most 3,000 IR code lines, established package/per-file limits, and the closed Python layout under `nkigym/src/nkigym`. *(2026-09-15 13:00 ET)*
17. **Hardware correctness and profiling share `nkigym.profile` and the current backend source.** Its single SSH/compiler/worker path captures exact outputs and latency from a per-run backend snapshot. Freeze source and ladders throughout acceptance; an older remote install cannot validate local edits. Tests must not duplicate transport or schedules. *(2026-09-15 13:00 ET)*
18. **Keep acceptance runs uninterrupted and isolate timed CPU rollouts.** Pausing the controller does not pause SSH deadlines and can turn a completed subprocess into a timeout. Competing simulation jobs can consume the rollout's fixed 600-second budget. *(2026-09-15 13:00 ET)*
19. **Analyze all transforms in the worker owning each rollout's IR.** Avoid per-transform serialization and repeated tree scans. Cache topology/access/pipeline facts with `WeakKeyDictionary` keyed by `KernelTree`; invalidate mutation-sensitive facts after rewrites. Performance-only changes must preserve ordered option lists so saved seeds follow the same choices. *(2026-09-15 13:00 ET)*
20. **OnlineFusion is contract-driven and incremental.** Preserve tile width and valid one-stage prefixes for arbitrary proven chains; reject deferred-factor recurrences. Completion requires a materialized SBUF contribution; only the loop advancing the recurrence may be shared across operations. Loop distribution, RFactor, and deleting previously dead producers remain separate actions. *(2026-09-15 13:00 ET)*
21. **SoftwarePipeline owns pipeline scheduling explicitly.** Source-child order is fixed, an action selects one contiguous two-stage boundary, and buffer versions are `use_stage - def_stage + 1` for on-chip buffers only. An active pipeline exposes only explicit all-zero removal before retuning; other transforms reject overlap instead of silently cancelling it. *(2026-09-15 13:00 ET)*
22. **Producer-consumer dependencies live in a sidecar ISA-leaf DAG.** Edges are overlapping same-buffer RAW/WAW/WAR tagged by tensor. Freeze directions from the original dependency graph when evaluating moves; rebuilding after motion can flip RAW to WAR and hide violations. *(2026-09-15 13:00 ET)*
23. **CodeMotion crosses one scope boundary or one adjacent sibling per action.** Allocation-scope entry and loop merging are separate. Match ordered concrete `(dimension, extent)` prefixes, never loop names. Preserve reset frequency and pipeline stages; invariant RMW cannot cross a plain-write reset. Reject full-buffer consumer replication and repeated invariant reads across overwrites. Non-bound target loops duplicate execution. *(2026-09-15 13:00 ET)*
24. **Buffer placement and compaction are separate actions.** Placement chooses a lifetime-safe allocation scope; compaction shrinks one logical shape and normalizes its regions while preserving `list_len`. Free-axis shrink appears only after motion makes the offset an enclosing anchor. *(2026-09-15 13:00 ET)*
25. **Buffer allocation form is performance-critical.** Multi-buffer degree is the second dimension of `(P, degree, F)`; tile count is a liveness-scheduled list. Factor `[P,T,F]` as `[[P,a,F]] x b` for any `a*b=T`, keep all tensors 3D, emit a uniform list even for `b=1`, and allocate at the tightest scope. *(2026-09-15 13:00 ET)*
26. **NKI allocation and register lifetimes follow control-flow regions.** Preserve `BlockNode` scopes with explicit NKI control flow; Python lexical scope is insufficient. Region-local register SSA values cannot escape without yielded results. Buffers feeding captured registers stay live through their last use because sequencers can defer register materialization. *(2026-09-15 13:00 ET)*
27. **BufferLayout conserves logical tiles and sets `list_len`; SoftwarePipeline sets versions.** A versioned list has `tiles_per_list * versions` physical slots, renderer indexing selects both components, and `analyze` enumerates every divisor of the tile count. *(2026-09-15 13:00 ET)*
28. **Split, Fuse, and RFactor have distinct atomic boundaries.** Split and Fuse replace exactly two adjacent factors per action. Split never partitions a slot reduction; RFactor owns the coordinated `ko/ki` split, reset, copy, and fold without reordering, placement, or compaction. *(2026-09-15 13:00 ET)*
29. **First-write overwrite and identity-initializer deletion are separate actions.** Marking the first reduction write as overwrite must leave the initializer intact; delete the initializer only after it is independently dead. *(2026-09-15 13:00 ET)*
30. **Generated `loop_var` strings are not globally unique.** Legality, normalization, and rewrite bookkeeping must key node IDs and ancestry, then perform substitutions within the selected block hierarchy; global name-keyed maps can rewrite unrelated sibling loops. *(2026-09-15 13:00 ET)*
31. **Operation contracts must declare implicit, non-tileable index domains as fixed axes.** Examples include `NKIRangeSelect`'s complete width, both configured widths of nonzero-with-count, and the eight-wide domains of max/find-index operations. Split/Fuse must preserve these constructor-fixed domains. *(2026-09-15 13:00 ET)*
32. **Never create trip-count-one `ForNode`s.** A dimension is factorized as `(trip_0, ..., trip_n, tensorize_size)`; loops represent only trips greater than one, the tensorize size is the ISA leaf width, and product-times-width equals the iteration domain. *(2026-09-15 13:00 ET)*
33. **BlockNode IR is structural.** The tree contains `BlockNode | ForNode | ISANode`; each block owns iter vars/values, regions, and allocations, and blocks are emitted mechanically one per operation. One axis has one role per block, so differing roles require separate blocks. *(2026-09-15 13:00 ET)*
34. **Loop roles are operation-local.** `ForNode` is role-neutral; block axes are PARALLEL, ACCUMULATION, or SEQUENTIAL. Reorder swaps one adjacent perfect-nest pair, rejects descendant sequential axes, and requires dependency endpoints to agree on whether each loop indexes their tensor. *(2026-09-15 13:00 ET)*
35. **`f_nkigym` is SSA and operations allocate-and-return.** Canonical build synthesizes memset from `RMW_OPERANDS`. *(2026-09-15 13:00 ET)*
36. **Buffer rewrites must preserve logical and physical dtypes separately.** Honor operation-specific storage overrides and require dtype compatibility for reuse, copy propagation, and in-place writes. PSUM matmul accumulation remains fp32 even with bf16 inputs; matching shape or byte width alone is insufficient. *(2026-09-15 13:00 ET)*
37. **Do not add `load_block`, `matmul_block`, or `allocate_buffers` gadgets.** Tile loops are positioned in IR; codegen emits explicit N-D `nl.ndarray` plus bare `nisa.dma_copy`, `nc_matmul`, and other one-to-one ISA calls at operation fire depth. *(2026-09-15 13:00 ET)*
38. **Codegen flows from IR primitives to source, never backward through `KernelIR`.** Sibling order is dataflow, loop names are dense `i_d{dim}_{N}`, and buffer declarations use first-use anchors independently from allocation scope. `KernelIR.dump()` writes only `envelope.md` and formatted `kernel.py`. *(2026-09-15 13:00 ET)*
39. **Expression rendering must preserve AST precedence.** Parenthesize compound substitutions in multiplication, floor division, and modulo; bare-variable tests miss incorrect BufferLayout, pipeline, and RFactor slot expressions. *(2026-09-15 13:00 ET)*
40. **Partition extent is operation-specific and at most 128.** Preserve fixed axes from operation contracts; `BufferLayout` must remain partition-agnostic and must not assume every buffer has `P = 128`. *(2026-09-15 13:00 ET)*
41. **Reduction initialization is a schedulable sibling block.** NKIGym is permanently post-`decompose_reduction`; do not port TVM init fields or nested `matmul.init`. Moving memset into the contraction loop re-zeroes live partial sums and violates producer-consumer order. *(2026-09-15 13:00 ET)*
42. **Respect Neuron material-blocking constraints.** Reading PSUM with material blocking open causes `NCC_ISCH714`; memset PSUM only for fp32, while bf16 transpose PSUM must not be memset. `tensor_scalar` operands and activation scale require fp32. *(2026-09-15 13:00 ET)*
43. **Transpose modeling stays ISA-accurate.** `dma_transpose` supports HBM-to-SBUF and SBUF-to-SBUF with matching dtypes; `NKITranspose` uses `nisa.nc_transpose(dst, data=...)`, SBUF-to-PSUM, matching dtype, and at most 128x128. Public tuning is pair insertion/cancellation plus operation-specific commute transforms. *(2026-09-15 13:00 ET)*
44. **The permanent architecture is an owned IR plus a TVM-derived arithmetic substrate, not a neuronx-cc fork.** `nkigym/ir/arith/` is a faithful standalone port with no shipped TVM dependency; use `detect_iter_map` where `can_prove_equal` cannot normalize div/mod identities. *(2026-09-15 13:00 ET)*
45. **Keep package imports lazy.** Eager exports from `nkigym/__init__.py` load compiler/synthesis dependencies into workers. Editable installs pin a source path across worktrees, so subprocess tests need `PYTHONPATH=<worktree>/nkigym/src` when the shared venv points elsewhere. *(2026-09-15 13:00 ET)*
