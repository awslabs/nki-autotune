27. **OnlineFusion is contract-driven and incremental.** Preserve tile width and valid one-stage prefixes for proven chains; reject deferred-factor recurrences. 28. **SoftwarePipeline owns pipeline scheduling explicitly.** Source-child order is fixed, an action selects one contiguous two-stage boundary, and buffer versions are `use_stage - def_stage + 1` for on-chip buffers only. An active pipeline exposes only explicit all-zero removal before retuning; other transforms reject overlap instead of silently cancelling it. *(2026-09-29 11:00 ET)*
29. **Producer-consumer dependencies form a sidecar ISA-leaf DAG.** Track overlapping same-buffer RAW/WAW/WAR edges tagged by tensor. Preserve original directions when evaluating moves; rebuilding afterward can flip RAW to WAR and hide violations. *(2026-09-29 11:00 ET)*
30. **CodeMotion crosses one scope boundary or adjacent sibling per action.** Allocation entry and loop merging are separate. Match ordered `(dimension, extent)` prefixes. Preserve reset frequency and pipeline stages; invariant RMW cannot cross plain-write resets. Reject full-buffer consumer replication and invariant rereads across overwrites. Non-bound target loops duplicate execution. *(2026-09-29 11:00 ET)*
31. **ProgramStorePartition requires terminal shared-output stores.** Partitioning a private intermediate store or an output read again can remove values each program still needs. *(2026-09-29 11:00 ET)*
32. **Buffer placement and compaction are separate actions.** Placement chooses a lifetime-safe allocation scope; compaction shrinks one logical shape and normalizes its regions while preserving `list_len`. Free-axis shrink appears only after motion makes the offset an enclosing anchor. *(2026-09-29 11:00 ET)*
33. **Buffer views distinguish logical shape from storage layout.** Use physical row pitch after padding, exclude padded elements even on width-one axes, and distinguish within-tile strides from inter-tile offsets. *(2026-09-29 11:00 ET)*
34. **Allocation form affects performance.** Multi-buffer degree is the second dimension of `(P, degree, F)`; tile count is a liveness-scheduled list. Factor `[P,T,F]` as `[[P,a,F]] x b` for any `a*b=T`. Keep tensors 3D, emit lists even for `b=1`, and allocate at the tightest scope. *(2026-09-29 11:00 ET)*
35. **NKI lifetimes follow control-flow regions.** Emit `BlockNode` scopes as NKI control flow; Python lexical scope is insufficient. Regrouping may extend buffer lifetimes despite unchanged ISA order. Region-local registers need yielded results to escape. Source buffers stay live through captured registers' last uses because sequencers can defer materialization. *(2026-09-30 09:00 ET)*
36. **BufferLayout conserves logical tiles and sets `list_len`; SoftwarePipeline sets versions.** A versioned list has `tiles_per_list * versions` physical slots, renderer indexing selects both components, and `analyze` enumerates every divisor of the tile count. *(2026-09-29 11:00 ET)*
37. **Split/Fuse replace exactly two adjacent factors per action.** Split excludes slot reductions; slot RFactor owns `ko/ki`, reset, and fold. Accumulate in independent FP32 output; stage only for aliasing/precision. Reordering, placement, and compaction remain separate. *(2026-09-30 09:00 ET)*
38. **Matrix RFactor folds private PSUM directly after the producer scope.** Staging copies and alignment require separate actions. Each private write must fit a 512-element bank. *(2026-09-29 11:00 ET)*
39. **First-write overwrite and identity-initializer deletion are separate actions.** Marking the first reduction write as overwrite must leave the initializer intact; delete the initializer only after it is independently dead. *(2026-09-29 11:00 ET)*
40. **Explicit PSUM overwrite can clear a 512-element bank.** Guard unsafe free-axis slices within a tile through subsequent transforms. Separate tile slots can remain compact. Validate intermediate layouts on hardware. *(2026-09-29 11:00 ET)*
41. **Generated `loop_var` strings are not globally unique.** Key legality, normalization, and rewrites by node IDs and ancestry. Limit substitutions to the selected hierarchy; global name maps can rewrite unrelated sibling loops. *(2026-09-29 11:00 ET)*
42. **Operation contracts must declare implicit, non-tileable index domains as fixed axes.** Examples include `NKIRangeSelect`'s complete width, both configured widths of nonzero-with-count, and the eight-wide domains of max/find-index operations. Split/Fuse must preserve these constructor-fixed domains. *(2026-09-29 11:00 ET)*
43. **Never create trip-count-one `ForNode`s.** A dimension is factorized as `(trip_0, ..., trip_n, tensorize_size)`; loops represent only trips greater than one, the tensorize size is the ISA leaf width, and product-times-width equals the iteration domain. *(2026-09-29 11:00 ET)*
44. **BlockNode IR is structural.** The tree contains `BlockNode | ForNode | ISANode`; each block owns iter vars/values, regions, and allocations, and blocks are emitted mechanically one per operation. One axis has one role per block, so differing roles require separate blocks. *(2026-09-29 11:00 ET)*
45. **Loop roles are operation-local.** `ForNode` is role-neutral; block axes are PARALLEL, ACCUMULATION, or SEQUENTIAL. Reorder swaps one adjacent perfect-nest pair, rejects descendant sequential axes, and requires dependency endpoints to agree on whether each loop indexes their tensor. *(2026-09-29 11:00 ET)*
