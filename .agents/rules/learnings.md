# Learnings

1. **Every public action is atomic and generic.** One workload-agnostic, semantics-preserving decision; every intermediate is correct. Intrinsic invariant repair is allowed. Retiling, reordering, forwarding, and producer deletion remain separate decisions; reject hidden composites, aliases, presets, wrappers, no-ops, and workload-specific implementations. *(2026-09-25 09:00 ET)*
2. **Transform legality is behavior/dependency order plus ISA well-formedness only, never resource capacity.** A dependency-legal kernel that oversubscribes PSUM or SBUF is valid output; compilation and hardware profiling prune it. Reject malformed IR, dependency violations, and ISA-impossible operations. *(2026-08-16 10:00 ET)*
3. **The optimization target is the literal manual-ladder endpoint.** Verify the expert source branch matches the frozen configuration. When MFU is flat, diff against that endpoint and close structural differences through atomic actions. *(2026-09-25 09:00 ET)*
4. **Respect the requested execution scope.** Status or timing requests call for pass/fail, durations, and seeds without debugging, fixing, filtering, or reducing coverage. When asked only to implement a test without running it, stop after implementation. Expected failures remain evidence until implementation is requested. *(2026-09-25 09:00 ET)*
5. **Scope `$develop-nkigym` edits to `nkigym/src/nkigym/` and best-ladder records in `kernel_library/`.** Follow current user authorization when resuming; stale goal wording must not re-block ladder updates. *(2026-09-25 09:00 ET)*
6. **Keep `$develop-nkigym` a persistent Codex goal.** Start immediately using actual goal tools and continue until all repository tests pass. Verified checkpoints do not complete the goal; after an explicit resume, continue authorized work despite stale tracker status. Pytest owns acceptance; add no second prompt. *(2026-09-25 09:00 ET)*
7. **Performance acceptance is full-registry mean relative latency.** `test/test_nkigym_ladder.py` requires `mean(nkigym_latency_ms / nakb_latency_ms) <= 0.9`, equally weighting all configurations and regressions. Prioritize reductions in this mean. Require correctness and a fresh complete run; mixed measurements are diagnostic. Draw a random 63-bit seed per benchmark; reserve `NKIGYM_NAKB_VALIDATION_SEED` for reproduction. *(2026-09-25 09:00 ET)*
8. **Pytest replays recorded ladders; it does not run agentic search.** Start from fresh canonical IR, require each recorded option to occur in `analyze`, apply sequentially, validate every intermediate numerically, then confirm final correctness and latency on Trn2. Use a simple loop; do not restore per-turn model orchestration or fixed search budgets. *(2026-09-25 09:00 ET)*
9. **NAKB acceptance uses each frozen target's Torch reference and AccuracySpec on seeded inputs and real Trn2 outputs.** ABI adapters cannot recompute answers. Preserve output selection, views, grouping, tolerances, and global-maximum or selected-value top-k comparison. Raw-byte equality is reserved for non-castable packed dtypes; CPU simulation is development coverage. *(2026-09-25 09:00 ET)*
10. **Preserve logical dtype, physical dtype, and observable rounding.** Honor operation-specific storage overrides in reuse, forwarding, fusion, and packing. Keep FP16/BF16 rounding before FP32 widening and FP32 PSUM accumulation with BF16 matmul inputs. Do not insert BF16 storage before FP8 conversion; tolerance checks alone cannot establish semantic preservation. *(2026-09-25 09:00 ET)*
11. **Reference fidelity can depend on accumulation and rounding order.** Higher-precision arithmetic can still fail a copied float32 reference; tiny upstream differences can cross FP8 quantization boundaries. Use the reference's operation and reduction order to diagnose these mismatches. *(2026-09-25 09:00 ET)*
12. **Tie handling follows the frozen target's comparison.** When top-k validates selected values, alternate tied indices are valid. Build MoE affinities and routing from the same selected indices; test ties with distinct expert weights because equal weights can hide incorrect routing. *(2026-09-25 09:00 ET)*
13. **Never relax repository acceptance gates to pass.** Preserve Black/isort, one-way imports, at most 30 public transforms and 3,000 IR code lines, package/per-file limits, and the closed Python layout under `nkigym/src/nkigym`. *(2026-09-25 09:00 ET)*
14. **The front end is PyTorch-only.** `synthesize_torch_to_nkigym` lowers Torch graphs and NAKB `TorchReference`s to `f_nkigym`, ABI adapters, and validated fp32 IR. Workloads never hand-code `f_nkigym`; remove NumPy compatibility paths. Synthesis has no model, prompt, search, or retry; current code/docs are authoritative. *(2026-09-25 09:00 ET)*
15. **Random-rollout coverage is fixed.** The first configuration of every workload except `hf_ffn` runs 500 transforms with a recorded random 63-bit seed and simulation at steps 50, 100, ..., 500. Generate concurrently; group simulations across all configured CPU hosts. One 600-second deadline covers synthesis through simulation. Registry and hardware coverage retain `hf_ffn`. *(2026-09-25 09:00 ET)*
16. **Numeric simulation is weaker than dependency-order legality.** Last-write-wins can make illegal memset or drain motion look numerically correct while breaking hardware. Treat behavior-preserving legality changes as golden-verdict changes and audit `illegal -> ok` transitions even when simulation stays green. *(2026-09-25 09:00 ET)*
17. **Hardware correctness and profiling share `nkigym.profile` and current backend source.** Its single SSH/compiler/worker path captures outputs and latency from a per-run snapshot. Freeze source and ladders during acceptance; old remote installs cannot validate local edits. Compare candidates with fresh controls; tests must not duplicate transport. *(2026-09-25 09:00 ET)*
18. **Verify the backend actually imported by pytest.** Editable installs pin a worktree, and pytest's configured `pythonpath` can override `PYTHONPATH`. Check `nkigym.__file__` and the transform registry before claiming prototype validation. *(2026-09-25 09:00 ET)*
19. **Keep acceptance uninterrupted and isolate timed CPU rollouts.** Pausing the controller leaves SSH deadlines running, causing false timeouts. Competing simulations consume the fixed 600-second rollout budget. *(2026-09-25 09:00 ET)*
20. **Isolate repository structure scans from Torch jobs.** Scans include ignored Python snapshots and transient Torch-generated files; concurrent synthesis or profiling can remove files mid-scan. Keep experiment snapshots outside the backend package or archived. *(2026-09-25 09:00 ET)*
21. **Public transforms directly define typed `analyze(ir)` and `apply(ir, option)`.** `apply` rechecks legality, copies, and fails loudly. The ordered `PUBLIC_TRANSFORM_TYPES`/`public_transforms()` registry must match the source-discovered inventory used by rollout and structure tests. *(2026-09-25 09:00 ET)*
22. **Analyze all transforms in the worker owning each rollout's IR.** Avoid per-transform serialization and repeated tree scans. Cache topology/access/pipeline facts by `KernelTree` in `WeakKeyDictionary`; invalidate mutation-sensitive facts after rewrites. Performance-only changes must preserve ordered options so saved seeds reproduce choices. *(2026-09-25 09:00 ET)*
23. **OnlineFusion is contract-driven and incremental.** Preserve tile width and valid one-stage prefixes for arbitrary proven chains; reject deferred-factor recurrences. Completion requires a materialized SBUF contribution; only the loop advancing the recurrence may be shared across operations. Loop distribution, RFactor, and deleting previously dead producers remain separate actions. *(2026-09-25 09:00 ET)*
24. **SoftwarePipeline owns pipeline scheduling explicitly.** Source-child order is fixed, an action selects one contiguous two-stage boundary, and buffer versions are `use_stage - def_stage + 1` for on-chip buffers only. An active pipeline exposes only explicit all-zero removal before retuning; other transforms reject overlap instead of silently cancelling it. *(2026-09-25 09:00 ET)*
25. **Producer-consumer dependencies live in a sidecar ISA-leaf DAG.** Edges are overlapping same-buffer RAW/WAW/WAR tagged by tensor. Freeze directions from the original dependency graph when evaluating moves; rebuilding after motion can flip RAW to WAR and hide violations. *(2026-09-25 09:00 ET)*
26. **CodeMotion crosses one scope boundary or adjacent sibling per action.** Allocation entry and loop merging are separate. Match ordered `(dimension, extent)` prefixes, never names. Preserve reset frequency and pipeline stages; invariant RMW cannot cross a plain-write reset. Reject full-buffer consumer replication and invariant rereads across overwrites. Non-bound target loops duplicate execution. *(2026-09-25 09:00 ET)*
27. **Buffer placement and compaction are separate actions.** Placement chooses a lifetime-safe allocation scope; compaction shrinks one logical shape and normalizes its regions while preserving `list_len`. Free-axis shrink appears only after motion makes the offset an enclosing anchor. *(2026-09-25 09:00 ET)*
28. **Buffer views distinguish logical shape from storage layout.** Padding changes physical row pitch; views and normalization use that pitch while excluding padding, including width-one axes. Keep within-tile stride separate from inter-tile offsets. *(2026-09-25 09:00 ET)*
29. **Allocation form affects performance.** Multi-buffer degree is the second dimension of `(P, degree, F)`; tile count is a liveness-scheduled list. Factor `[P,T,F]` as `[[P,a,F]] x b` for any `a*b=T`. Keep tensors 3D, emit lists even for `b=1`, and allocate at the tightest scope. *(2026-09-25 09:00 ET)*
30. **NKI allocation and register lifetimes follow control-flow regions.** Preserve `BlockNode` scopes with explicit NKI control flow; Python lexical scope is insufficient. Region-local register SSA values cannot escape without yielded results. Buffers feeding captured registers stay live through their last use because sequencers can defer register materialization. *(2026-09-25 09:00 ET)*
31. **BufferLayout conserves logical tiles and sets `list_len`; SoftwarePipeline sets versions.** A versioned list has `tiles_per_list * versions` physical slots, renderer indexing selects both components, and `analyze` enumerates every divisor of the tile count. *(2026-09-25 09:00 ET)*
32. **Split, Fuse, and RFactor have distinct atomic boundaries.** Split and Fuse replace exactly two adjacent factors per action. Split never partitions a slot reduction; RFactor owns the coordinated `ko/ki` split, reset, copy, and fold without reordering, placement, or compaction. *(2026-09-25 09:00 ET)*
33. **First-write overwrite and identity-initializer deletion are separate actions.** Marking the first reduction write as overwrite must leave the initializer intact; delete the initializer only after it is independently dead. *(2026-09-25 09:00 ET)*
34. **Generated `loop_var` strings are not globally unique.** Legality, normalization, and rewrite bookkeeping must key node IDs and ancestry, then perform substitutions within the selected block hierarchy; global name-keyed maps can rewrite unrelated sibling loops. *(2026-09-25 09:00 ET)*
35. **Operation contracts must declare implicit, non-tileable index domains as fixed axes.** Examples include `NKIRangeSelect`'s complete width, both configured widths of nonzero-with-count, and the eight-wide domains of max/find-index operations. Split/Fuse must preserve these constructor-fixed domains. *(2026-09-25 09:00 ET)*
36. **Never create trip-count-one `ForNode`s.** A dimension is factorized as `(trip_0, ..., trip_n, tensorize_size)`; loops represent only trips greater than one, the tensorize size is the ISA leaf width, and product-times-width equals the iteration domain. *(2026-09-25 09:00 ET)*
37. **BlockNode IR is structural.** The tree contains `BlockNode | ForNode | ISANode`; each block owns iter vars/values, regions, and allocations, and blocks are emitted mechanically one per operation. One axis has one role per block, so differing roles require separate blocks. *(2026-09-25 09:00 ET)*
38. **Loop roles are operation-local.** `ForNode` is role-neutral; block axes are PARALLEL, ACCUMULATION, or SEQUENTIAL. Reorder swaps one adjacent perfect-nest pair, rejects descendant sequential axes, and requires dependency endpoints to agree on whether each loop indexes their tensor. *(2026-09-25 09:00 ET)*
39. **`f_nkigym` is SSA and operations allocate-and-return.** Canonical build synthesizes memset from `RMW_OPERANDS`. *(2026-09-25 09:00 ET)*
40. **Do not add `load_block`, `matmul_block`, or `allocate_buffers` gadgets.** Tile loops are positioned in IR; codegen emits explicit N-D `nl.ndarray` plus bare `nisa.dma_copy`, `nc_matmul`, and other one-to-one ISA calls at operation fire depth. *(2026-09-25 09:00 ET)*
41. **Codegen flows from IR primitives to source, never backward through `KernelIR`.** Sibling order is dataflow, loop names are dense `i_d{dim}_{N}`, and buffer declarations use first-use anchors independently from allocation scope. `KernelIR.dump()` writes only `envelope.md` and formatted `kernel.py`. *(2026-09-25 09:00 ET)*
42. **Expression rendering must preserve AST precedence.** Parenthesize compound substitutions in multiplication, floor division, and modulo; bare-variable tests miss incorrect BufferLayout, pipeline, and RFactor slot expressions. *(2026-09-25 09:00 ET)*
43. **Partition extent is operation-specific and at most 128.** Preserve fixed axes from operation contracts; `BufferLayout` must remain partition-agnostic and must not assume every buffer has `P = 128`. *(2026-09-25 09:00 ET)*
44. **Reduction initialization is a schedulable sibling block.** NKIGym is permanently post-`decompose_reduction`; do not port TVM init fields or nested `matmul.init`. Moving memset into the contraction loop re-zeroes live partial sums and violates producer-consumer order. *(2026-09-25 09:00 ET)*
45. **Engine selection obeys each operation's ISA contract.** Strided copies may have stricter engine requirements than ordinary copies. Arithmetic engines can differ in signed zero, rounding, and numerical range; copy equivalence does not establish arithmetic equivalence. *(2026-09-25 09:00 ET)*
46. **Respect Neuron material-blocking constraints.** Reading PSUM with material blocking open causes `NCC_ISCH714`; memset PSUM only for fp32, while bf16 transpose PSUM must not be memset. `tensor_scalar` operands and activation scale require fp32. *(2026-09-25 09:00 ET)*
47. **Transpose modeling stays ISA-accurate.** `dma_transpose` supports HBM-to-SBUF and SBUF-to-SBUF with matching dtypes; `NKITranspose` uses `nisa.nc_transpose(dst, data=...)`, SBUF-to-PSUM, matching dtype, and at most 128x128. Public tuning is pair insertion/cancellation plus operation-specific commute transforms. *(2026-09-25 09:00 ET)*
48. **Leave allocation addresses to Neuron's Chaitin-Briggs zone-aware allocator.** Explicit `address=` annotations bypass `AddressRotation::run` and can disable its allocation rotation. *(2026-09-25 09:00 ET)*
49. **The permanent architecture is an owned IR plus a TVM-derived arithmetic substrate, not a neuronx-cc fork.** `nkigym/ir/arith/` is a faithful standalone port with no shipped TVM dependency; use `detect_iter_map` where `can_prove_equal` cannot normalize div/mod identities. *(2026-09-25 09:00 ET)*
