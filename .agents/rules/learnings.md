# Learnings

## Code Quality
- Don't rebuild derived maps in hot paths — cache on `id(obj)` at module level (per-call `inspect.getsource` = 50×+ slower). *(2026-04-23 10:00 ET)*
- **No `load_block`/`matmul_block`/`allocate_buffers` gadgets** — tile loops IR-positioned; bare `nl.ndarray`+`nisa.dma_copy`/`nc_matmul` at op fire depth. **`nl.ndarray` N-D explicit** `(P, num_p_tiles, F_contig)`, bare `128` (no `nl.par_dim`). *(2026-04-26 11:00 ET)*
- **Loud failures only**: no silent raises, no `try/except` to adapt around malformed IR — reject bad input. A no-op-on-bad-input transform returning "success" is the same violation. **Single return per function** (user rejects branching returns). *(2026-06-01 22:00 ET)*
- **Transform legality = behavior/dep-order + ISA well-formedness ONLY; NEVER resource capacity** (user-locked): a dep-legal kernel that over-subscribes PSUM/SBUF is a VALID output — compile/HW profiling prunes it (gym-1 CONFIRMED). DO reject malformed IR / dep violations / ISA-impossible ops; DON'T gate "won't fit in PSUM". *(2026-07-03 10:00 ET)*

## Architecture
- **`nkigym/__init__.py` lazy `__getattr__`**: eager re-exports drag heavy deps into gym workers — keep `__init__` empty of compile/synthesis loads. **Editable pip install pins source path** across shared-venv worktrees: subprocess tests pick up installed path not cwd → `PYTHONPATH=<worktree>/nkigym/src`. *(2026-05-07 13:00 ET)*
- **Neuron allocator** Chaitin-Briggs+zone-aware: `address=` annotations skip `AddressRotation::run` → ~48pp MFU loss. *(2026-04-26 04:00 ET)*
- **Material-blocking**: reading PSUM w/ open material-blocking → `NCC_ISCH714` (also on aliased `address=` RAW). Memset PSUM only when `PSUM_DTYPE=fp32`; transpose bf16 PSUM must NOT memset → `NCC_IBIR441`. HW mandates fp32 for `tensor_scalar.operand0/1`, `activation.scale`. *(2026-04-23 10:00 ET)*
- **Path B (own IR) > Path A (fork neuronx-cc)** — Path A ceiling = compiler IR (no online fusion/rotation/SW-pipeline/PSUM-bank addrs). **Decision: PORT TVM's TensorIR schedule layer + `arith`**. *(2026-06-03 02:00 ET)*
- **arith substrate SHIPPED (`nkigym/ir/arith/`)**: faithful TVM `src/arith/` port; shipped code and tests import zero TVM. Native cases plus byte-exact ladders/simulation are canonical coverage; optional TVM parity oracles were removed because CI and `install.sh` never carried TVM. `can_prove_equal` can't fold `(f//c)*c+f%c→f` — use `detect_iter_map`. *(2026-07-24 01:00 ET)*
  - **Test organization**: dedup/parametrize active coverage, split direct behavior from render/simulation integration, remove obsolete diagnostics and stale cases, and preserve every active assertion.
- **Repo scope**: `NKIOps` + `KernelIR` build and render NKI. `KernelIR.dump()` writes only `envelope.md` and formatted `kernel.py`; the user removed the Mermaid/PNG backend and Node/browser dependencies. *(2026-07-17 13:00 ET)*
- **NO trip-1 ForNodes anywhere**: a dim's iteration = factorization `(trip₀…trip_{k-1}, tensorize_size)`; ForNode ONLY when trip>1; innermost `tensorize_size` = ISA-leaf width. **Three layers**: `iter_var.dom`, ForNode trips, `BufferRegion (lo,width)`; `Π(trip)×width==dom`. *(2026-06-01 02:00 ET)*
- **BlockNode IR** (`tree.py`, nx.DiGraph): payload union `BlockNode|ForNode|ISANode`. `BlockNode` (TVM `SBlock`) owns `iter_vars` (axis+`dom`+role), `iter_values`, `reads`/`writes`, `alloc_buffers`. **Blocks mechanically emitted** one-per-op; ONE role per axis → differing role forces own block. *(2026-06-07 20:00 ET)*
- **SSA ops backend**: `f_nkigym` is SSA — `out = NKIOp()(src=…)`, allocate-and-return; memset synthesized in `canonical_build` from `RMW_OPERANDS`. **Dtype** (`Buffer.physical_dtype`): PSUM accum ALWAYS fp32 (ONLY hardcode); else 1st HBM input. *(2026-06-01 22:00 ET)*
- **LCA buffer placement is explicit**: each `Buffer` belongs to the LCA BlockNode of all touching blocks; `shared_hbm` stays at root. CodeMotion/RFactor are structural-only, and downstream `BufferCompaction` materializes placement for a selected on-chip buffer. *(2026-07-17 13:00 ET)*
  - **Buffer alloc FORM is MFU-CRITICAL, NOT inert** (MEASURED): k22 matched the manual endpoint's compute body yet ran **46.6% vs 90.7%** — pure buffer form (manual endpoint: list of `(128,1,512)` tiles IN-loop → double-buffered; ours: ONE packed `(128,D,F)` → serialized loads). [[nki-buffer-allocation-granularity]].
  - **Free-axis shrink is a CodeMotion→BufferCompaction composition property**: it shrinks to 512 only after the offset becomes enclosing anchor `i_d2_0`, not from `Split(d2)` alone.
- **Buffer-alloc granularity = the on-chip multi-buffer lever** (user-corrected): **multi-buffer degree** = 2nd dim `(P,deg,F)` (atomic, pinned); **number-of-tiles** = a **`list`** (liveness-scheduled) — lifting tiles to a list is the MFU knob ([[nki-buffer-allocation-granularity]]). All tensors 3D even at deg/tiles=1; alloc at tightest scope. **Target model: tile axis factorizes `[P,T,F] → [[P,a,F]]×b` for ANY `a·b=T`** (`Buffer.list_len`=`b`); **codegen emits UNIFORM list even for `b=1`** (perf-neutral). **`BufferLayout` CONSERVES tiles — re-factorizes `a·b=T`, never creates** (`[P,2,F]×8` double-buffer = SoftwarePipeline's `versions`). *(2026-07-06 16:00 ET)*
  - **Partition axis P = MAX 128, NOT always-128** (user-corrected): per-op min/max caps ARE already fields (`MIN_TILE_SIZE`/`MAX_TILE_SIZE: ClassVar[dict[str,int|None]]`). But P is PINNED to exactly 128 by `MIN["P"]=128` AND a redundant `PARTITION_DIM` (`tree.py:35`, asserts `leading%128==0`) → P<128 UNREPRESENTABLE today = separate future plan, NOT a missing field. **`BufferLayout` P-agnostic** — factorizes tile axis T, passes `0:P` through.
- **Producer-consumer deps = sidecar DAG** (`ir/dependency.py`, networkx; ISA-leaf nids only). The tree stays block-structural. Edges are overlapping same-buffer RAW/WAW/WAR tagged by `tensor`; static scheduling uses `must_precede`, while CodeMotion evaluates positions and promoted spans. *(2026-07-17 13:00 ET)*
  - **Code-motion legality = span-promotion plus reset-frequency preservation**. `first_backward_edge_for_insertion` promotes an invariant RMW access to a carrying loop unless a plain-write init breaks carry. `_check_no_rmw_reset_scope_change` separately rejects moving either an invariant reset or its RMW across a loop when edge direction alone cannot expose the changed reset frequency.
  - **Dep directions: freeze from ORIGINAL `ir.dependency`** — NEVER rebuild on MOVED tree (RAW→WAR flip hides the violation → NaN); eval via `first_backward_edge_for_insertion` on the PRE-move tree ([[span-promotion-needs-frozen-directions]]).
- **Codegen direction: ir → codegen, never reverse.** Renderer takes IR primitives (tree/block nodes, `BufferRegion`s), not `KernelIR`. **loop_var naming**: dense `i_d{dim}_{N}` (N = ordinal outer→inner). **Sibling order = dataflow**. **Buffer decls emit anchored to first-use child** (`_alloc_emit_anchors`, `body.py`; NOT `alloc_buffers` list order); *scope* (LCA) and *position* = separate levers. **Renderer output IS canonical style** — kwarg ISA + slice indexing. *(2026-06-24 11:00 ET)*
- **Transform API**: `analyze` enumerates legal options; `apply` deep-copies, re-checks, mutates, and fails loudly. OnlineFusion matches use-def chains through operator contracts and lowers explicit `SEQUENTIAL` recurrences to ordinary ISA nodes; exhaust existing transform compositions before adding capabilities. FlashAttention must expose TWO incremental OnlineFusion actions: max+exponentiated-sum into `(m,l)`, then that recurrence+value matmul into output. The current maximal-chain action is an implementation gap. Production gate: single-head noncausal 16Kx16Kx128 BF16; CPU correctness and 46.4% fused versus 18.2% transformed non-fusion and 51.25% Kaena MFU. *(2026-07-29 11:00 ET)*
- **Agentic refinement (`nkigym.search`) is deliberately linear**: profile the canonical state; show Neuron metrics and legal actions; let the policy choose one transform or finish; profile every result; retain the best measured state. `autotune.search` owns only Neuron profiler adapters. Tree search, bootstraps, random rollouts, checkout/resume, and explicit evaluation decisions were removed. *(2026-07-26 11:00 ET)*
- **BufferCompaction SHIPPED**: the per-buffer transform places an on-chip declaration at its LCA, shrinks its logical shape to the access bounding box, and normalizes regions into the materialized IR frame. It rejects shared-HBM and no-op choices; CodeMotion/RFactor no longer compact implicitly. *(2026-07-17 13:00 ET)*
- **TVM init = TWO-state model** (detail in `tvm_knowledge.md`): default WELDED (PREDICATED `if reduce==min`); `decompose_reduction` extracts a schedulable `SBlockRV`. **We're PERMANENTLY post-decompose** → never port init-field/predication/`decompose_reduction`. *(2026-06-09 12:00 ET)*
- **CodeMotion = same-prefix merge on dependent dimensions** (replaces TVM `solve_iter_domains`): match ordered `(dim, extent)` pairs, never generated `loop_var` names; retain NID identity for shared ambient loops and execution-scope checks; rebind removed-loop uses to target variables and normalize only the moved block. Non-bound target loops are duplication loops (valid for producer/reload, rejected for accumulation). Split/Reorder/Fuse must first make the dependent prefix match. *(2026-07-18 01:00 ET)*
- **SoftwarePipeline** assigns `(stage, order)` to child blocks and derives `Buffer.versions = use_stage−def_stage+1`; no capacity gate. Small bodies use exhaustive labelings; large bodies enumerate all contiguous two- and three-stage partitions in $O(n^2)$. *(2026-07-29 11:00 ET)*
- **RFactor is structural and intentionally narrow**: it supports one two-way `ko/ki` split for a 2D PSUM read-modify-write reduction, canonical init/identity-drain blocks, contiguous affine footprints, and `add`/`multiply`. It flips `ko` ACC→PAR and inserts the reset/copy/fold around `ki` as one semantic atom; axes, domains, and placement are source-derived. It does not compact buffers: `k32→k33` is RFactor, `k33→k34` compacts PSUM, and `k34→k35` compacts staging. Deeper reduction nests, `"slot"`, nonzero `factor_axis`, and remapped drains are rejected. *(2026-07-18 01:00 ET)*
- **BufferLayout** conserves logical tiles and sets `list_len`; it commutes with SoftwarePipeline. A versioned list has `tiles_per_list * versions` physical slots, and renderer indexing selects both the list-local tile and pipeline slot. `analyze` enumerates every divisor of T. *(2026-07-29 11:00 ET)*
  - **Latent `a>1` render precedence bug caught ONLY by whole-branch review** (`e397cf9`): `_format_raw(FloorDiv(lo,a))` on COMPOUND `lo=i*4+j` emits `i*4 + j//a` not `(i*4+j)//a` → OOB; reachable (`analyze` OFFERS `list_len=8`). **Ladder missed it (only `a=1`/`b=1` endpoints); both unit tests used a bare `Var`** — the accidentally-correct shape. *(2026-07-06 20:00 ET)*
  - **Legality checks key NIDs, NOT loop_vars** (`ed5f61a`; post-RFactor foreign-K & own-`ko` both named `i_d0_0` → loop_var keys alias-collide → over-rejection blocked fold-inlining). Fixed with no new transform / no IR overhaul. See [[fused-rfactor-design-analysis]].
- **Memset = sibling block, NOT nested `matmul.init`** (`BlockNode.init` dropped; permanently post-`decompose_reduction`). **memset-into-K = plain producer-before-consumer** (re-zeros a live partial-sum → NaN); subsumed by span-promotion. *(2026-07-03 10:00 ET)*
- **Loop-role placement (OP-LOCAL)**: `ForNode` is role-neutral; roles live on `BlockNode.iter_var` and may differ by op. Roles are PARALLEL, ACCUMULATION, and SEQUENTIAL. Reorder swaps one adjacent perfect-nest pair, rejects descendant SEQUENTIAL axes, and requires internal dependency endpoints to agree on whether each swapped loop indexes their tensor. *(2026-07-17 13:00 ET)*
- **Matmul hardware gate**: `test_manual_ladders.py` requires the byte-exact `kernel_35` endpoint to reach at least 90% MFU on gym-1; latest 90.6155%, historical SOTA 90.92% versus nkipy 86.65%. MAC = 4·SEQ²·D (attention), `K·M·N`. *(2026-07-28 09:00 ET)*
- **ISA / transpose**: `dma_transpose` supports HBM→SBUF and SBUF→SBUF with matching dtypes. `NKITranspose` emits `nisa.nc_transpose(dst, data=...)` (not `src=`), SBUF→PSUM, matching dtype, max 128x128; PSUM location does not itself force fp32. Layout tuning exposes only `InsertTransposePair`, `CancelTransposePair`, and operation-specific `TransposeThrough{Load,Matmul,TensorCopy}` commutes; no macros or compatibility wrappers. Pair insertion names an exact producer-consumer edge, and every intermediate preserves behavior. Canonical matmul uses the actual extent below N's 512 maximum. Matmul K/M≤128, N≤512; `activation_reduce` free cap 16384/partition; `tensor_scalar.operand0` broadcasts free. **NKIOp = ISA 1:1.** *(2026-07-26 11:00 ET)*
